# 화면 목록·흐름도 (v1, 2026-11-25)

## 화면 목록
| ID | 화면 | 주요 요소 |
|---|---|---|
| S1 | 기록 | 일간/주간/월간 전환, ◀ 기간 ▶·오늘, 한 일·할 일·메모 입력, 저장 상태, (주간·월간) 이 기간의 일간 기록 |
| S2 | 목록 | 검색창, 전체/일간/주간/월간 필터, 기록 카드(누르면 S1 해당 기간으로) |
| S3 | 설정 | GitHub 소유자·저장소·브랜치·파일 경로·토큰, 연결 확인, 지금 동기화, 마지막 동기화 시각, 토큰 지우기 |

## 흐름도
```mermaid
flowchart LR
  A[앱 실행] --> S1[S1 기록: 오늘 일간]
  S1 -- 일간/주간/월간 --> S1
  S1 -- ◀ ▶ 오늘 --> S1
  S1 -- 입력 --> SAVE[자동 저장(로컬)]
  S1 -- 하단 탭 --> S2[S2 목록]
  S2 -- 카드 누름 --> S1
  S1 -- 하단 탭 --> S3[S3 설정]
  S3 -- 동기화 --> GH[(GitHub 저장소 JSON)]
  GH -- 합치기 --> SAVE
```

## 동기화 규칙
1. 저장소 파일을 받는다(없으면 빈 것으로 본다).
2. 기록마다 `updatedAt` 이 더 늦은 쪽을 남긴다. 삭제는 `deletedAt` 표시로 전달한다.
3. 합친 결과를 로컬에 저장하고, 저장소에 올린다(파일 sha 로 충돌 감지, 충돌 시 1회 다시 시도).
