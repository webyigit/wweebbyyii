## 한 줄 요약

> 헌금은 **한 번만** 입력하면 → 주간 헌금현황, 개인별 집계, 기부금영수증, 예결산서가 **자동으로** 나온다.

## 중요: 이 폴더에는 실제 교인 정보를 넣지 않습니다

이 저장소는 GitHub Pages 로 **공개**되어 있습니다. 교인 이름·헌금액·주민번호 같은 실제 데이터는
절대 커밋하지 않고, 클라우드 DB(접근권한 있는 사람만)에만 저장합니다. 예시가 필요하면 가짜 이름(홍길동 등)을 씁니다.
