## 2. 기술 선택 (결정 + 이유)

| 영역 | 선택 | 이유 |
|---|---|---|
| 웹/앱 | **PWA** (React + Vite) — 필요하면 나중에 Capacitor 로 앱스토어용 포장 | 코드 하나로 웹·안드로이드·아이폰·PC 모두. 스토어 심사 없이 '홈 화면에 추가'로 설치 |
| 클라우드 DB | **Supabase** (PostgreSQL + 로그인 + 행 단위 권한) | 무료 한도로 교회 규모 충분, 표준 SQL 이라 나중에 옮기기 쉬움, 권한 관리 내장 |
| 로컬 DB | 브라우저 **IndexedDB** (Dexie) | 기기 안에 전체 사본 → 오프라인 입력·빠른 조회 |
| 동기화 | 로컬 먼저 저장 → '보낼 목록'에 쌓았다가 연결되면 클라우드로, 클라우드 변경은 받아와 반영 | 주일 예배당 와이파이가 불안정해도 입력이 안 멈춤 |
| 보고서 | 화면 → 인쇄/PDF (주간현황·영수증·결산서 양식) | 지금 종이 결재 방식을 그대로 이어감 |
| 민감정보 | 주민번호는 **암호화 저장**, 영수증 담당자만 열람 | 개인정보보호법 |
| 백업 | 매일 자동 백업 + 언제든 **엑셀로 내보내기** | '엑셀로 돌아갈 수 있다'는 안심 장치 |

## 3. 입력을 줄이는 방법 (R2 의 핵심)

1. **한 번 입력, 모든 곳 반영** — 헌금 1건이 주간현황·개인별 집계·영수증·결산에 동시에 쓰임
2. **이름 자동완성 + 교인 번호** — 두 글자 치면 후보, 동명이인은 가정/구역으로 구분
3. **지난주 명단 불러오기** — 매주 같은 분이 내는 십일조·선교헌금은 명단이 미리 떠 있고 금액만 확인
4. **가정 단위 입력, 개인 단위 영수증** — `홍길동,김영희` 한 줄로 받고 영수증 분배 규칙은 한 번만 설정
5. **고정지출 자동 생성** — 사례비·이자처럼 매월 정해진 주에 나가는 지출은 규칙으로 한 번 등록 → 그 주가 되면 미리 채워짐, 확인만
6. **은행 거래내역 올리기** — 농협·수협 거래내역 엑셀을 올리면 자동 분류(한 번 분류하면 기억), 장부와 자동 대사
7. **기부금영수증 신청서를 온라인으로** — 종이 대신 링크/QR 로 본인이 직접 입력(주민번호는 암호화). 작년 신청자는 "올해도 같음" 한 번만 누르면 끝
8. **가정 단위 영수증** — 가족을 한 가정으로 묶고 신청자 1명을 지정하면, 가족 전원 헌금이 자동으로 그 사람 영수증에 합쳐짐
9. **자동 계산** — 누계·진도율·잔액·월/연 합계·영수증 금액은 사람이 절대 안 씀
10. (나중) 헌금봉투 사진 → 글자 인식으로 초안 입력

## 4. 단계와 일정

오늘이 9월 말이고 **영수증은 1월, 결산은 1~2월 공동의회**가 마감이라 거기서 거꾸로 짰습니다.

| 단계 | 기간(목표) | 만드는 것 | 끝나면 고객이 할 수 있는 것 |
|---|---|---|---|
| **0. 분석·설계** | 9월 말 ~ 10월 1주 | 엑셀 분석, 계정과목표, DB 설계, 화면 흐름, 질문 정리 | 설계 검토·확정 |
| **1. 헌금 입력 + 주간현황 (MVP)** | 10월 1~3주 | 로그인, 교인 명부, 헌금 입력, 주간 헌금현황 자동 출력 | **엑셀과 병행해서 매주 실사용 시작** |
| **2. 과거 데이터 이관 + 개인별 집계** | 10월 4주 ~ 11월 1주 | 2026년 1~현재 엑셀 → DB 이관, 이름 정리(동명이인·가정 묶음), 개인별 집계 화면 | 엑셀 숫자와 **원 단위까지 일치** 확인 |
| **3. 지출 + 계좌 대사** | 11월 | 부서·항목 예산표, 고정지출 규칙, 추가 지출 입력, 주간 수입/지출 보고서, 농협·수협 거래내역 자동분류·대사, 차입 현황 | 출납회계가 날짜 탭 복사 없이 매주 보고서 출력 |
| **4. 기부금영수증** | 11월 말 ~ 12월 | 가정별 신청자 지정, **온라인 신청서**(주민번호 암호화), 법정 양식 출력, 발행대장 | 12월에 신청 링크 배포 → 1월에 **버튼으로 일괄 발행** |
| **5. 예결산** | 12월 ~ 1월 | 2027 예산 편성 화면, 2026 결산서 자동 작성, 예산 대비 집행 | 공동의회 자료 출력 |
| **6. 앱·오프라인 마무리** | 1월 | 설치형 앱, 오프라인 입력·동기화 다듬기, 사용 설명서 | **엑셀 완전 중단** |

각 단계 끝마다: 고객 확인 → HISTORY.md 기록 → 다음 단계.
