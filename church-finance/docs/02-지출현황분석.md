# 02. 지출 관리 현황 분석

작성: 2026-09-28 · 근거: 드라이브의 `금주보고서_수입지출_출납`, `2026년도 상반기 지출 상세내역` (실명·계좌번호는 옮기지 않음)

## 1. 지금 매주 하는 일 (시트의 '업무순서' 탭 그대로)

| 단계 | 하는 일 | 새 프로그램에서 |
|---|---|---|
| 1 | 지난주 탭을 **복사해서** 이번 주 탭 생성 → 금액 초기화 → 지난주 잔액 맞는지 확인 | **없어짐** (주차는 날짜로 자동, 잔액은 이어서 계산) |
| 2-1 | '매주 고정지출' 표에서 **복사·붙여넣기** | **자동 생성** — 이번 주가 몇째 주인지 보고 해당 고정지출을 미리 채움, 사람은 확인만 |
| 2-2 | 부교역자가 카톡으로 보낸 지출내역 입력 | 추가 지출 입력 (영수증 사진 첨부 가능) |
| 2-3·2-4 | 농협 출금(자동이체)을 그룹으로 묶어 합계 / 상세 입력 | **거래내역 엑셀 올리기 → 자동 분류** (처음 한 번 분류하면 다음부터 기억) |
| 2-5 | 농협 출금 합계 = 장부 지출 합계인지 확인 | **자동 대사** — 안 맞으면 빨간 표시 |
| 2-6 | 부서별 시트에 제대로 들어갔는지 확인 | 부서별 집계는 자동이라 확인 불필요 |
| 2-7 | 추가 지출 입력 후 다시 합계 확인 | 입력 즉시 반영 |
| 4 | 주간보고 기준으로 담당자에게 송금 | 송금 목록(받는 사람·계좌·금액) 자동 정리 → 사람이 은행에서 송금 |

## 2. 지출 분류 체계 = 예산 과목표

- **부서 13개**: 예배부, 봉사부, 장년교육부, 교회학교부, 전도부, 관리부, 음악부, 재정부, 특별사역팀, 사회복지부, 차량관리부, 이웃사랑선교부 (+ 부서별 담당 장로·권사·집사 1명)
- **항목 약 65개**: 부서 아래 세부 항목(예: 관리부 → 주보발행비·인쇄비·공공요금 …), 항목마다 **연 예산**
- 상반기 보고서는 `부서 → 항목 → 지출 건` 순서로 **예산·지출·잔액·집행률**을 보여 줌 → 결산서의 뼈대가 됨
- 예산 초과 시 "다른 항목에서 지출" 같은 비고가 있음 → **항목 간 전용** 기록 기능 필요

## 3. 주간 수입/지출 보고서 한 장의 구성 (`MM-DD` 탭)

- 결재란: 출납회계 → 재정부장 → 당회장
- 수입/지출 요약: 일반헌금·특별헌금별 `지난주 잔액 + 수입 − 지출 = 잔액`
- 특별헌금별 잔액 (이웃사랑·꽃꽂이·건축)
- **차입 현황** (은행 대출, 해외선교 차입) · 입금 예정 금액
- 지출 상세: `순번 · 내용 · 금액 · 부서 · 항목 · 비고(받는 사람)`
- 자체 검산: "오류없음" 표시

## 4. 고정 지출의 모양

`몇째 주 · 내용 · 금액 · 부서 · 항목 · 받는 사람/계좌` — 사례비, 연금 지원, 대출이자(+적금), 복사기 임대, 홈페이지 관리 등.
→ 새 프로그램에서는 **'고정지출 규칙'** 으로 한 번 등록 (금액이 오르면 규칙만 수정, 예: "26년도 10만원 인상").

## 5. 계좌

- **NH농협**: 운영 계좌 (자동이체·송금이 여기서 나감)
- **수협**: 대출·적금
- → 두 계좌 모두 거래내역 올리기 대상. 잔액이 장부와 맞는지 매주 자동 확인.
