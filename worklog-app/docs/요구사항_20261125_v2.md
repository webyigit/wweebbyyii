# 업무 기록 앱 요구사항 (v2, 2026-11-25)

v1(하루·주·달 단위 메모)에서 사용자가 준 상세 명세에 맞춰 **업무(할 일) 체크리스트** 중심으로 바꿨습니다.

## 1. 사용자
| 사용자 | 상황 | 바라는 것 |
|---|---|---|
| 본인(기획자) | 아이폰으로 출퇴근·회의 사이 업무 확인 | 열자마자 아직 못 끝낸 일, 한 번 눌러 완료 |
| 본인(PC) | 회사 PC 브라우저 | 같은 기록을 넓은 화면에서도 |
| 본인(일정 관리) | 못 한 일 미루기, 다음 달 일 미리 넣기 | 미루기·예약·알림 |

| ID | 기능 | 우선순위 | 상태 |

| F1 | 업무 기록(추가) | 필수 | 완료 |

| F3 | 다른 날로 미루기(내일·다음 주 월요일·날짜 고르기), 미룬 횟수·처음 날짜 표시 | 필수 | 완료 |

| F12 | 말줄임 없이 전체 내용 | 필수 | 완료 |
| F13 | 수정·삭제(삭제 후 되돌리기) | 필수 | 완료 |
| F14 | 필터: 전체·완료·미완료 | 필수 | 완료 |

## 3. 비기능
- 저장: 기기 안(AsyncStorage) 먼저, 인터넷 없어도 동작. 저장 데이터가 깨지면 원본을 따로 보관하고 덮어쓰지 않음.
- 보안: GitHub 토큰은 SecureStore(키체인)만, 공개 저장소 동기화 차단.
- 접근성: 터치 44pt, 스크린리더 라벨·상태, 완료는 색 말고 취소선·체크로도 구분.
- PC: 가운데 한 단(최대 640px), 토스 정책대로 다단 레이아웃 안 씀.
