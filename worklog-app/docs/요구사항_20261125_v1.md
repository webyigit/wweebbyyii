# 업무 기록 앱 요구사항 (v1, 2026-11-25)

## 1. 목적
하루·한 주·한 달 단위로 한 일과 할 일을 짧게 남기고, 나중에 다시 찾아본다.
기록은 기기에 먼저 저장하고, 원하면 내 GitHub 저장소에 백업·동기화한다.

## 2. 사용자
| 사용자 | 상황 | 바라는 것 |
|---|---|---|
| 본인(기획자) | 출퇴근·회의 사이 아이폰으로 짧게 기록 | 3초 안에 오늘 기록 열기, 저장 버튼 없이 자동 저장 |
| 본인(주간·월간 정리) | 주간 보고·월간 회고 작성 | 그 주·그 달의 일간 기록을 한 화면에서 모아 보기 |
| 본인(기기 변경·안드로이드) | 폰을 바꾸거나 안드로이드 추가 | GitHub 에서 기록을 그대로 불러오기 |

## 3. 기능 목록·우선순위
| ID | 기능 | 우선순위 | 비고 |
|---|---|---|---|
| F1 | 일간·주간·월간 전환 | 필수 | 상단 탭 |
| F2 | 기간 이동(이전·다음·오늘) | 필수 | 주는 ISO 주(월요일 시작) |
| F3 | 기록 작성: 한 일 / 할 일 / 메모 3칸 | 필수 | 입력 멈추고 0.6초 뒤 자동 저장 |
| F4 | 기기 로컬 저장 | 필수 | AsyncStorage, 인터넷 없어도 동작 |
| F5 | 주간·월간 화면에서 해당 기간 일간 기록 모아 보기 | 필수 | 펼치기/접기 |
| F6 | 전체 목록·검색 | 필수 | 기간 종류별 필터 |
| F7 | 기록 삭제 | 필수 | 확인 후 삭제, 동기화 시 삭제도 반영 |
| F8 | GitHub 동기화(받기+합치기+올리기) | 필수 | 저장소 JSON 파일 1개, 최신 수정 우선 |
| F9 | GitHub 토큰 보안 저장 | 필수 | 기기 보안 저장소(SecureStore)만 사용, 저장소·로그에 안 남김 |
| F10 | 연결 확인 | 권장 | 저장소 접근·쓰기 권한 확인 |
| F11 | 알림(퇴근 시간 기록 알림) | 나중에 | v2 |
| F12 | 주간·월간 보고서 내보내기(마크다운 공유) | 나중에 | v2 |

## 4. 비기능 요구
- **플랫폼**: iPhone 우선. Expo(React Native)라 같은 코드로 Android 빌드 가능.
- **보안**: 토큰은 SecureStore(iOS 키체인, Android Keystore)에만. 웹 미리보기에서는 메모리에만 두고 저장 안 함. 비공개(private) 저장소 권장.
- **접근성**: 버튼 44pt 이상, 스크린리더 라벨, 시스템 글자 크기 대응.
- **오프라인**: 동기화 실패해도 로컬 기록은 그대로.

## 5. 범위 밖(v1)
앱스토어 배포(사전 승인 필요), 여러 사람 공유, 첨부 사진.

## 용어
- ISO 주: 월요일 시작, 그 해 첫 목요일이 든 주가 1주차인 국제 표준 주 번호[^1]
- SecureStore: Expo 가 제공하는 기기 보안 저장소 래퍼[^2]

[^1]: ISO 8601 주 번호 규칙
[^2]: https://docs.expo.dev/versions/latest/sdk/securestore/
