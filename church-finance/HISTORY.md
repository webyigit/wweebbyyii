## 2026-09-28 (3) · 0단계 · 실제 주간 파일 분석

**고객 제공**: 어제 작성한 최신 파일 `★ 09-27_수입지출내역` (출납회계 작성). `09-27` 시트를 매주 작성하고, **`총` 시트와 `09-27` 시트를 출력해 제출**.

**한 일**
1. 파일(시트 27장)을 받아 시트마다 값과 수식을 뽑아 구조를 분석 → `docs/03-주간수입지출파일-분석.md`
   - 제출물 2장(`MM-DD`, `총`) + 이것을 만들기 위한 원장·검산 시트 25장
   - 매주 **파일 전체를 복사**해서 새로 만든다는 것 확인 (파일 이름 `★ MM-DD_수입지출내역`)
2. `PLAN.md` 갱신: 3단계 산출물을 "주간 보고서 + 누계 보고서"로 명시, 온라인 헌금 자동 매칭 추가, 5단계에 제직회 보고서 추가

**발견과 결정**
- `✔️/❌` 검산 수식이 수십 개 → 담당자가 정확성을 가장 중시. **새 프로그램도 검산 결과를 눈에 보이게** 둔다
- 농협 입금 메모에 `이름+헌금종류`가 적혀 온라인 헌금이 들어옴 → **메모 자동 매칭**으로 기장회계 입력을 줄인다
- 복사를 거듭하며 수식이 깨진 흔적(`#REF!`) → 원본 데이터 하나에서 계산하는 구조가 해결책
- 이미 `결산예산`·`제직회` 시트가 있어 **예결산 양식의 기준**으로 삼는다

**다음 할 일**

## 2026-09-28 (2) · 0단계 · 고객 답변 반영, 지출 쪽 분석

**고객 답변**
- Q1 지출: 구글시트에 날짜 이름 탭을 매주 만들어 입력. **고정 지출 + 출납회계가 추가로 입력하는 지출**
- Q2 사용자: 입력 2명(기장회계·출납회계), 열람 2명(재정부장·담임목사)
- Q3 영수증: 이름·전화·주소·주민번호를 매년 종이 신청서로 받아 수동 발행
- Q4 가족 헌금: 가정마다 신청자 1명에게 가족 전원 헌금을 몰아서 발행 (신청자는 거의 고정)

**한 일**
1. 드라이브에서 지출 쪽 시트(`금주보고서_수입지출_출납`, `상반기 지출 상세내역`)를 찾아 분석 → `docs/02-지출현황분석.md`
   - 시트 안에 이미 '업무순서'가 적혀 있었음: 지난주 탭 복사 → 초기화 → 고정지출 붙여넣기 → 농협 출금 입력 → 합계 검산 → 송금
   - 지출 분류는 **부서 13개 × 항목 약 65개**, 항목마다 연 예산 → 이것이 곧 예결산의 뼈대
2. `PLAN.md` 갱신: 권한표 확정, 입력 줄이기 방법 추가(고정지출 자동 생성, 온라인 영수증 신청서, 가정 단위 영수증), 3·4단계 내용 구체화
3. `docs/QUESTIONS.md` 의 Q1~Q4 를 '확인됨'으로 옮김

**결정과 이유**
- **고정지출은 '규칙'으로 한 번 등록**: 매주 복사·붙여넣기가 사라지고, 금액 인상 시 규칙 하나만 고치면 됨
- **영수증 신청서를 온라인으로**: 입력을 교인 본인이 하게 되어 담당자 타이핑이 사라짐. 작년 신청자는 "올해도 같음" 확인만
- **'가정' 단위 모델**: 가정 = 여러 교인 + 영수증 신청자 1명. 헌금은 누가 냈든 가정에 쌓이고 영수증은 신청자 이름으로
- **결재 대신 '확인' 표시**: 재정부장·담임목사는 열람권자라서 결재 흐름을 만들지 않고 "확인함" 기록만 남김

**다음 할 일**
