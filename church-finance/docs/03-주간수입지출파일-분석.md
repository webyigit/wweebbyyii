# 03. 주간 수입지출 파일 분석 (출납회계 작성본)

작성: 2026-09-28 · 근거: 드라이브 `★ 09-27_수입지출내역` (2026-09-27 작성, 시트 27장). 실명·계좌번호는 옮기지 않음.

## 1. 한 줄 요약

**출납회계가 매주 이 엑셀 파일 전체를 복사해 새 파일(`★ MM-DD_수입지출내역`)을 만들고**,
그 안의 `MM-DD` 시트를 채운 뒤 **`MM-DD` 시트 + `총` 시트를 출력해 제출**합니다.
나머지 25장은 이 두 장을 만들기 위한 누계·검산용입니다.

## 2. 시트 27장의 역할

| 묶음 | 시트 | 하는 일 | 새 프로그램에서 |
|---|---|---|---|
| **제출물** | `MM-DD` (예: 09-27) | 이번 주 수입/지출: 일반·특별 `지난주 잔액+수입−지출=잔액`, 특별헌금별 잔액, **지출 상세**(순번·내용·금액·부서·항목·비고), 해외선교 입출금, 차입 현황, 결재란(출납회계·재정부장·당회장) | **주간 보고서 화면 → 인쇄/PDF** (같은 모양) |
| **제출물** | `총` | 연간 누계 보고서(당회 재정보고용): 일반·특별별 `예산·전년이월·올해헌금·지출·잔액`, 헌금 항목별 예산 대비 수입률, **부서 13개별 예산 대비 집행률**, 특별헌금·해외선교·네팔구호 잔액, 차입 현황, 계좌 목록, 재정부장·출납·기장 이름, 감사위원 | **누계 보고서 화면 → 인쇄/PDF** |
| 규칙 | `고정지출` | 첫째~넷째 주별 정기 지출(사례비·연금·이자·임대료…) + 송금 받는 사람 계좌 | **고정지출 규칙** (한 번 등록) |
| 원장 | `기장` | 주(날짜)별 열 × 항목별 행 — 헌금 항목별 수입, 일반/특별 지출, 주간·월·연 누계, 잔액 | **자동 계산** (DB에서 합계) |
| 원장 | `수입` | 이번 주 헌금 항목별 금액 — **현금/온라인 구분** | 헌금 입력에서 자동 |
| 원장 | `특별헌금` | 이웃사랑·꽃꽂이·건축 각각의 입출금 장부 | 자동 |
| 원장 | `해외선교` | 해외선교헌금 입출금 (월말 송금) | 자동 |
| 원장 | 부서 12장 (`예배`~`특별사역`) | 부서별 항목 예산·지출·잔액·집행률 + 지출 건별 내역 + 부장 이름·임무 | **부서별 화면** (자동) |
| 은행 | `NH` | 농협 거래내역 붙여넣기 — **입금 메모에 `이름+헌금종류`**(예: `홍길동십일조`)가 적혀 있음 | **거래내역 올리기 → 자동 매칭** |
| 검산 | `검증` | 주별 `농협 통장 잔액 + 입금예정 = 장부 잔액` 확인, 해외선교 미입금 잔액 | **자동 대사** |
| 검산 | `입력확인` | 부서별 주간 지출 매트릭스로 `총`과 부서 시트가 같은지 확인 | 불필요 (원본이 하나라서) |
| 연간 | `결산예산` | 2026 예산·실적·달성률 + **2027 예산안·증감률** + 예산 조정 검토(증액/신설 사유) | **5단계 예결산 화면** |
| 보고 | `제직회`, `제직회_요약`, `재직회_상세(상반기)`, `재직_해외선교보고` | 반기 제직회 보고: 수입·지출 합계(한글 금액 표기), 전년 대비 증감, 부서별 지출 상세, 해외선교 보고 | **5단계 보고서** (반기/연간) |

## 3. 눈에 띄는 점

| # | 발견 | 의미 |
|---|---|---|
| F1 | 시트 곳곳에 `✔️/❌` **자체 검산 수식**이 수십 개 | 담당자가 숫자 정확성을 매우 중요하게 여김 → 새 프로그램도 **검산 결과를 화면에 그대로 보여 줘야** 신뢰를 얻음 |
| F2 | `NH` 시트에 `#REF!` 오류, 과거 주 값은 **숫자로 붙여넣기** 되어 있음 | 파일 복사를 반복하면서 수식이 깨짐 → 원본 데이터 하나에서 계산하면 사라짐 |
| F3 | **온라인 헌금**이 농협 입금 메모(`이름+종류`)로 들어옴 | 기장회계의 입력을 크게 줄일 기회: 메모를 읽어 교인·항목 자동 매칭, 사람은 애매한 것만 확인 |
| F4 | 계좌가 여러 개: 농협(일반·대출), 우리(외화), 신한(적금), 수협(대출) + 차입 2건 | 계좌·차입 관리 화면 필요 |
| F5 | 특별헌금 지출이 일반 지출 목록에 섞여 있고 `부서=특별헌금`으로 구분 | 지출 입력 시 **'회계(일반/특별/해외선교)'** 를 먼저 고르게 함 |
| F6 | 네팔 긴급구호처럼 **한시 헌금**이 생김 | 헌금 항목을 담당자가 직접 추가할 수 있어야 함 |
| F7 | 예산 초과 시 다른 항목(예비비 등)에서 지출하고 비고에 적음 | **항목 간 전용** 기록 → 다음 해 예산 조정 근거로 자동 수집 |
| F8 | 매주 파일 전체를 새로 복사 (2MB × 52주) | 파일 복사 자체가 없어짐 |

## 4. 역할 분담 (확인됨)

- **기장회계**: 헌금 쪽 (개인별 헌금, 주일헌금현황)
- **출납회계**: 이 파일 — 수입 합계를 받아 지출·잔액·누계·보고서
- 제출: `MM-DD` + `총` 출력물 → 재정부장·당회장(담임목사)
