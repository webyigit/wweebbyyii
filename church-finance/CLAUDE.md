- **실제 교인 이름·금액·주민번호·계좌번호를 이 폴더에 절대 쓰지 마세요.** 저장소가 공개입니다.
  예시·테스트 데이터는 가짜 이름(홍길동, 김영희 …)으로 만듭니다.
- 작업을 하면 **반드시 `HISTORY.md` 에 한 항목을 추가**하세요. 날짜 / 한 일 / 왜 / 결정사항 / 다음 할 일.
  사용자가 나중에 이 기록으로 남에게 과정을 설명합니다. 개발자가 아닌 사람도 읽을 수 있게 씁니다.
- **히스토리를 정리할 때는 구글 슬라이드 발표자료도 함께 갱신하세요.** 히스토리 전체를 요약해서,
  누구나 이 자료 하나만 들고 발표(PT)할 수 있게 만듭니다.
  - 원본: `slides/build.js` (슬라이드 내용 + **슬라이드마다 발표자 노트**) → `node build.js` → `history.pptx`
  - 구글 드라이브 폴더 `교회재정관리_프로젝트기록`(id `1GJjbPK6LSxm5BFxKp2sGWXj196ytT1VS`)에
    `create_file` 로 올려 Google Slides 로 변환 (base64 가 길어서 하위 에이전트에게 맡기면 편함)
  - 드라이브 도구는 파일 내용을 덮어쓰지 못합니다. 새 판을 올리고, 옛 판은 제목 앞에 `[이전] ` 을 붙여 둡니다.
  - 올린 뒤 PDF 로 내보내(`download_file_content`, exportMimeType `application/pdf`) 글자 넘침을 눈으로 확인
  - 실명·금액·계좌번호 금지는 슬라이드에도 똑같이 적용
