# church-finance 에서 작업할 때

- **실제 교인 이름·금액·주민번호·계좌번호를 이 폴더에 절대 쓰지 마세요.** 저장소가 공개입니다.
  예시·테스트 데이터는 가짜 이름(홍길동, 김영희 …)으로 만듭니다.
- 작업을 하면 **반드시 `HISTORY.md` 에 한 항목을 추가**하세요. 날짜 / 한 일 / 왜 / 결정사항 / 다음 할 일.
  사용자가 나중에 이 기록으로 남에게 과정을 설명합니다. 개발자가 아닌 사람도 읽을 수 있게 씁니다.
- 고객에게 물어볼 것은 `docs/QUESTIONS.md` 에 모으고, 답을 받으면 같은 파일에 "확인됨"으로 옮깁니다.
- 작업을 마칠 때 `NEXT.md` 의 "지금 어디까지 왔나 / 다음 할 일" 을 갱신하세요. 사용자가 휴대폰 등 다른 기기에서 새 세션으로 이어갑니다.
- 계획이 바뀌면 `PLAN.md` 를 고치고, 바뀐 이유를 `HISTORY.md` 에 남깁니다.
- 원본 엑셀은 구글 드라이브에 있습니다(소유: 교회 재정 계정). 읽기만 하고 수정하지 않습니다.
