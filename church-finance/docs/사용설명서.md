# 교회 재정관리 앱 — 사용 설명서

앱 주소 (PC·휴대폰 모두): https://webyigit.github.io/wweebbyyii/church-finance/

- 설치할 것 없음. 휴대폰은 브라우저 메뉴의 **"홈 화면에 추가"** 를 누르면 앱처럼 쓸 수 있습니다.
- 인터넷이 끊겨도 열리고 입력됩니다. 다시 연결되면 자동으로 올라갑니다 (로그인한 경우).
- 모든 금액 칸은 `50000`, `5만`, `1만5천`, `1억1천만` 처럼 편하게 넣으면 됩니다.

## 매주 (주일)

### 기장회계 — 헌금

1. **헌금 입력** 탭: 과목(십일조·감사…)을 누르고 → 이름 앞글자나 초성(`ㅎㄱㄷ`) → 금액 → Enter
   - 지난주 명단이 옆에 나와서 한 번에 넣을 수 있습니다. 처음 보는 이름은 새 가정으로 등록됩니다.
   - 주일헌금처럼 이름 없는 헌금은 총액만 넣습니다.
2. **주일헌금현황** 탭 → **인쇄 / PDF** (지금 양식 그대로)

### 출납회계 — 지출·통장

1. **지출 입력** 탭: 그 주 **고정지출이 미리 떠 있으니 확인만** → "한 번에 추가". 그 밖의 지출을 입력.
2. **통장 내역** 탭: 농협 인터넷뱅킹에서 받은 거래내역 엑셀을 올리면
   - 입금: 메모로 헌금자·과목을 자동으로 찾아 '온라인 헌금'으로 (모르는 건 체크 안 됨 → 골라 주기)
   - 출금: 한 번 고른 항목은 기억해서 다음부터 자동
3. **수입지출 보고** 탭 → 주간 / 연 누계 → **인쇄 / PDF** (`MM-DD`·`총` 시트와 같은 두 장)
   - 위쪽 "✔ 검산 이상 없음" 을 확인
4. **재정 현황** 탭 → 현금 잔액을 적으면 **장부와 실제 돈이 맞는지** 바로 나옵니다 (✔ 또는 차이 금액)

### 모두 — 백업 (1주에 한 번)

**계정·백업** 탭 → **전체 백업 받기** → 받은 파일을 교회 구글 드라이브의 백업 폴더에 올리기.
(마지막 백업이 7일 넘으면 빨간 글씨로 알려 줍니다)

## 반기·연말

### 제직회 (6월·12월) — **예결산·제직회** 탭

- **요약 보고**: 수입·지출 합계(한글 금액), 예산 대비, **작년 같은 기간 대비**, 결론 문장이 자동으로
- **지출 현황**: 부서·항목별 예산·지출·진행률·잔액
- **부서별 상세**: 항목마다 지출 한 건씩 (받는 사람은 체크해야 보임)
- **해외선교**: 이월·주별 헌금·송금·잔액
- 기간: 1월~기준일 / 상반기 / 하반기 / 1년 — 모두 **인쇄 / PDF**

### 예산 편성 (11~12월) — **예결산·제직회 → 결산·예산(안)**

1. 위쪽 **예산 조정 검토** 목록(예산 넘은 항목·예산 없이 쓴 항목·연말 초과 예상)을 보며
2. 각 줄 오른쪽 칸에 **내년 예산(안)** 입력 → 증감률·수입/지출 균형이 바로 계산
3. **엑셀로 내보내기** → 예결산위원회·공동의회 자료
4. 1월이 되면 넣어 둔 예산(안)이 그대로 올해 예산이 됩니다

### 기부금영수증 (12월 말~1월) — **기부금영수증** 탭

1. **발급** 화면: 가정별 1년 헌금이 신청자에게 모여 있음. 위쪽 합계 검산 확인
   - 신청자가 없는 가정은 아래 목록에서 "신청자 정하기" (두 사람이 나누면 비율 %)
2. **신청자** 화면: 새 신청서의 주민번호·주소 입력 (저장하는 순간 잠김)
3. 위쪽에 **영수증 비밀번호**를 넣고 → "발급 안 된 N명 모두 고르기" → **발급·인쇄**
   - 법정 서식(별지 제45호의2) 한 장씩. 교회 직인은 인쇄 후 날인
4. **발급대장** 화면: 인쇄·엑셀. 잘못 발급했으면 "폐기"(사유) 후 다시 발급 → 새 번호

### 새해 첫 주

- **예산·이월**: 전년 이월(1월 1일 잔액)이 맞는지 확인 — 작년 연 누계 보고의 잔액과 같아야 함
- **전체 백업 받기** (한 해 마감본으로 따로 보관)

## 문제가 생기면

- 위쪽 표시가 **"동기화 오류"**: 계정·백업 탭에서 "지금 동기화". 계속되면 인터넷 확인 후 로그아웃·로그인
- **"등록되지 않은 계정"**: 재정부장에게 이메일 등록 요청 (Supabase `app_users`)
- 숫자가 엑셀과 다름: 수입지출 보고 → **엑셀과 대조** 로 어느 칸인지 확인
- 기록을 잘못 지움: 가장 최근 백업에서 되살리기 (되살리기 전 지금 상태도 백업 받아 두기)
