# 01. 현재 엑셀 관리 현황 분석

작성: 2026-09-28 · 근거: 구글 드라이브의 재정 관련 스프레드시트 (읽기만 함, 실제 이름·금액은 옮기지 않음)

## 1. 지금 쓰는 파일들

| 파일 | 주기 | 하는 일 |
|---|---|---|
| `MM-DD_주일헌금현황` | **매주 1개씩 새로 만듦** | 그 주 헌금 명세 + 예산 대비 누계·진도율, 결재란 |
| `★★ 2026년도 개인별 헌금집계 ★★` | 1년 1개, 월별 시트 12장 + 합계 | 사람별 1년 합계 → 기부금영수증 금액 |
| `[2025년도] 개인별 헌금 총합계 및 영수증 발행금액` | 1년 1개 | 영수증 발행 금액 확정본 |
| `건축(E/V)헌금_수입지출내역_2026년도` | 1년 1개 | 건축헌금 별도 수입·지출 |
| `구로 남도교회 '수협(Sh BANK)'계좌 현황` | 수시 | 계좌 잔액·입출금 |
| `2026년도 남도교회 제5남선교회 회비 현황` | 1년 1개 | 기관(선교회) 회비 — 범위 밖일 수 있음 |
| `2023/2024년도 헌금 집계 .xlsx` | 과거 | 이관 대상 과거 데이터 |

## 2. 주간 헌금현황의 구조 (이게 사실상 '계정과목표')

```
일반회계 (예산 있음, 진도율 관리)
├─ 십일조
├─ 주일헌금            ← 이름 없이 총액만
├─ 감사헌금 = 범사감사 + 기타감사(내용 적음) + 일천번제
├─ 기타:   신년감사, 기관헌금(유치부·아동부·중고등부·청년부)
└─ 절기헌금: 부활절, 맥추감사절, 추수감사절, 성탄절
특별회계 (예산 없음)
├─ 이웃사랑헌금
├─ 꽃꽂이헌금 (내용 적음)
└─ 건축(E/V)헌금
해외선교헌금   ← 위 합계에 안 들어가고 따로 표시됨 (월말에 실제 송금)
```

한 장에 들어가는 것:
- 머리: 날짜, 교회명, **결재란 3단 (기장회계 → 재정부장 → 당회장)**
- 요약표: 항목별 `예산(A) / 이번 주 / 지난주까지 / 총누계(B) / 진도율 B÷A`
- 명세: 항목마다 `성명 · 금액 (· 내용)` 을 4열로 나열

## 3. 개인별 헌금집계의 구조

- 월 시트: `일자 | 구분 | 성명 | 금액 | 비고` 한 줄 = 헌금 한 건
- 옆에 성명별 월합계, 합계 시트에 1~12월 이어붙인 연합계 + 기부금영수증용 금액

## 4. 발견한 문제점 (= 새 프로그램이 풀어야 할 것)

| # | 문제 | 새 프로그램에서 |
|---|---|---|
| P1 | **같은 헌금을 두 번 입력** — 주간현황에 한 번, 개인별 집계에 또 한 번 | 한 번 입력 → 모든 보고서 자동 |
| P2 | 개인별 집계가 **7월부터 비어 있음** (주간현황은 8월 말까지 있음) → 옮겨 적기가 밀림 | 옮겨 적기 자체가 없어짐 |
| P3 | 합계 시트에 **`#N/A` 다수** — 이름 찾기(VLOOKUP) 실패 | 이름이 아니라 교인 번호로 연결 |
| P4 | 이름을 **부부·가족 묶음 문자열**로 적음 (예: `홍길동,김영희`) → 영수증은 개인 단위라 나눠야 함 | '헌금 단위(가정)'와 '영수증 받는 사람'을 분리 |
| P5 | **동명이인**을 `이름A` 같은 꼬리표로 구분, 오타로 같은 사람이 두 줄 | 교인 번호 + 이름 자동완성 |
| P6 | 무명·무명1·무명2 … 표기 | '무명' 전용 처리 (영수증 제외) |
| P7 | 매주 파일을 복사해서 새로 만듦 → 지난주 누계를 손으로 넘김 | 누계는 DB에서 계산 |
| P8 | 해외선교헌금: 주일에 받고 **월말에 송금** → 어느 회계에 언제 잡을지 모호 | 수입(받은 날)과 송금(지출)을 따로 기록 |
| P9 | 지출 기록 파일을 아직 못 찾음 → 예결산의 '지출' 쪽 근거 필요 | 고객에게 확인 (QUESTIONS Q1) |
| P10 | 결재가 종이/서명 기반으로 보임 | 화면에서 결재 버튼 (기록 남음) |
