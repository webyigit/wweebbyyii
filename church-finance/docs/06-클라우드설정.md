# 06. 클라우드(Supabase) 계정 만들기 — 교회 담당자용 안내

PC와 휴대폰의 데이터를 서로 맞추고(동기화), 4명이 각자 로그인해서 쓰려면 인터넷에 데이터베이스가 하나 있어야 합니다.
**Supabase**(무료)를 씁니다. 계정은 **교회 소유**여야 나중에 담당자가 바뀌어도 안전하므로, 교회 재정용 이메일로 만들어 주세요.

걸리는 시간: 약 10분 · PC 에서 하는 게 편합니다 (휴대폰도 가능)

---

## 1. 가입

1. https://supabase.com 에 들어가서 오른쪽 위 **Start your project** (또는 **Sign up**)
2. **이메일로 가입**: 교회 재정용 구글 메일 주소와 새 비밀번호 입력
   - GitHub 로 가입하는 버튼도 있지만, 교회 계정이 아니면 쓰지 마세요
3. 받은 편지함의 **확인 메일**에서 링크를 누르면 가입 끝

## 2. 조직(Organization) 만들기

처음 들어가면 조직을 만들라고 나옵니다.

| 칸 | 넣을 값 |
|---|---|
| Name | `남도교회 재정부` |
| Type | Personal 또는 Non-profit (아무거나) |
| Plan | **Free** (무료) |

## 3. 프로젝트 만들기

**New project** 를 누르고:

| 칸 | 넣을 값 |
|---|---|
| Project name | `church-finance` |
| Database Password | **Generate a password** 눌러 자동 생성 → **복사해서 안전한 곳에 보관** (교회 금고 문서 등) |
| Region | **Northeast Asia (Seoul)** — 가장 빠름 |

**Create new project** → 1~2분 기다리면 준비됩니다.

> ⚠ Database Password 는 **저(Claude)를 포함해 누구에게도 보내지 마세요.** 앱 연결에는 필요 없습니다.

## 4. 연결 정보 2가지를 알려 주세요

프로젝트 화면 위쪽 **Connect** 버튼(또는 왼쪽 아래 톱니바퀴 **Project Settings → API**)에서:

| 이름 | 모양 | 보내도 되나 |
|---|---|---|
| **Project URL** | `https://abcdefgh.supabase.co` | ✅ 보내 주세요 |
| **anon / public key** (또는 **Publishable key**) | `eyJ…` 또는 `sb_publishable_…` 로 시작하는 긴 글자 | ✅ 보내 주세요 (공개용 열쇠 — 앱 화면에도 들어가는 값) |
| service_role / secret key | `sb_secret_…` 등 | ❌ **절대 보내지 마세요** |
| Database Password | 3단계에서 만든 것 | ❌ **절대 보내지 마세요** |

공개용 열쇠(anon)만으로는 아무것도 볼 수 없습니다. 제가 데이터베이스에 **"로그인한 4명만, 각자 권한만큼"** 규칙(RLS)을 걸어 둡니다.

## 5. (나중에) 사용자 4명 초대

연결이 끝나면 앱의 설정 화면에서 기장회계 · 출납회계 · 재정부장 · 담임목사의 이메일을 넣으면 초대 메일이 갑니다. 지금은 안 하셔도 됩니다.

## 알아 두실 것

- **무료 한도**: 데이터 500MB — 교회 헌금·지출 기록 수십 년치가 들어가고도 남습니다.
- **1주일 동안 아무도 안 쓰면 잠깁니다**(무료 정책). 매주 쓰므로 문제없고, 잠겨도 대시보드에서 버튼 하나로 다시 켜집니다.
- **백업**: 기기마다 전체 사본이 있고, 앱에서 언제든 엑셀로 내보낼 수 있게 만듭니다.
- 교회가 커지거나 자동 백업이 필요하면 유료(월 약 25달러)로 바꿀 수 있지만, 지금은 필요 없습니다.
