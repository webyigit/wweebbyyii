# 가게 사진

여기에 사진을 넣으면 카드 위에 뜹니다. 파일 이름은 `index.html` 데이터 블록의
`photo` 값과 같아야 합니다. 예를 들어 `"photo": "photos/특삼겹.jpg"` 라면
이 폴더에 `특삼겹.jpg` 를 두면 됩니다.

`crawl_naver_place.py` 를 돌리면 네이버 플레이스 사진을 `photos/` 에 저장하고
`photo` 값도 자동으로 채웁니다 (사진 없이 돌리려면 `--no-photos`).
이미 같은 이름의 파일이 있으면 덮어쓰지 않으므로, **직접 찍은 사진을 먼저 넣어 두면
크롤링이 그 위를 건드리지 않습니다.**

권장 사양: 가로 800px 이상, 16:10 비율에 가깝게, JPG.

## 저작권

크롤링으로 받아지는 사진은 가게나 다른 손님이 네이버에 올린 것입니다. **개인적으로 보는
용도로만** 쓰세요. 나중에 이 페이지를 외부에 공개하거나 다시 배포할 생각이라면, 그 전에
직접 찍은 사진으로 바꿔야 합니다.
