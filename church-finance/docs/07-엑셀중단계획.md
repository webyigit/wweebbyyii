# 07. 엑셀 중단 계획 (6단계: 병행 운영 → 전환)

목표: 앱만으로 1년을 운영. 엑셀은 **결과가 같다는 것이 확인될 때까지만** 함께 씁니다.

## 1. 준비 (1주)

- [ ] 4명 가입, 위쪽 표시가 **● 동기화됨** (`docs/06-클라우드설정.md` 7번)
- [ ] 기장회계 가입 후 `supabase/update.sql` 실행
- [ ] 올해 자료 가져오기: 개인별 헌금집계, 주간 명단(월별 폴더), 최신 출납 파일 → **엑셀 가져오기**
- [ ] 작년 자료: `총계정원장_2025` → **엑셀 가져오기** (요약 보고의 '작년 대비')
- [ ] 통장·현금·차입 등록 (**재정 현황**) → 대사 ✔ 확인
- [ ] 교회 정보·영수증 비밀번호·예전 발급 현황표 (**기부금영수증 → 설정·가져오기**)
- [ ] **전체 백업 받기** → 교회 드라이브

## 2. 병행 운영 (4주 권장)

매주 지금처럼 엑셀도 쓰고, 앱에도 같은 내용을 넣은 뒤:

1. **수입지출 보고 → 엑셀과 대조** 에 그 주 출납 파일(★ MM-DD_수입지출내역)을 고르기
2. 모든 칸 ✔ 이면 그 주 통과. ✘ 칸이 있으면 어느 쪽이 맞는지 확인해 고치기
   - 지금까지 알려진 엑셀 쪽 차이: 9/27 이웃사랑헌금 기장 310,000 ↔ 주간 시트 155,000 (Q11)
3. **주일헌금현황**도 엑셀 주간 현황과 나란히 놓고 과목별 합계 확인
4. **재정 현황** 대사 ✔ 확인

## 3. 전환

4주 연속 모두 ✔ 이면:

- [ ] 제출물을 앱 인쇄본으로 바꿈 (주간 수입/지출, 연 누계, 주일헌금현황) — 재정부장 확인
- [ ] 엑셀 파일은 **읽기 전용으로 보관** (지우지 않음)
- [ ] 매주 백업을 교회 드라이브에 (앱이 7일 넘으면 알려 줌)
- [ ] 이 결정을 `HISTORY.md` 에 기록

## 4. 전환 뒤 1년 동안 한 번씩 확인

- [ ] 6월 제직회: **예결산·제직회 → 요약 보고** 로 보고
- [ ] 11~12월: 내년 예산(안)을 앱에서 편성
- [ ] 12월 말~1월: 기부금영수증 앱에서 일괄 발급
- [ ] 1월: 전년 이월 확인, 한 해 마감 백업
