# 알림 · iOS 위젯 연동 안내 (v1, 2026-11-25)

## 1. 본체 앱에 붙이는 법 (3줄)

```tsx
// App.tsx
import { startReminderBridge, subscribeOpenRequests } from './src/reminders';
useEffect(() => startReminderBridge(), []);
useEffect(() => subscribeOpenRequests((r) => { /* 일간 탭 + r.date 로 이동, r.taskId 강조 */ }), []);
```

```tsx
// 업무 행 우측
import ReminderSheet from './src/reminders/ReminderSheet';
import ReminderButton from './src/reminders/ReminderButton';
<ReminderButton task={t} onPress={() => setSheetTask(t)} />
{sheetTask && <ReminderSheet task={sheetTask} visible onClose={() => setSheetTask(null)} />}
```

저장은 `taskStore.update(id, { remindAt })` 만 씁니다. 기기 알림 예약·위젯 갱신은 bridge 가 taskStore 변경을 듣고 알아서 맞춥니다.

## 2. 동작

| 기능 | 내용 |
|---|---|
| 알림 시트 | 빠른 선택 3개(오늘 업무: 30분 뒤·1시간 뒤·오후 6시 / 예약 업무: 그날 9시·13시·전날 21시) + 직접 고르기(날짜·오전/오후·시·분 5분 단위) · 알림 끄기 |
| 권한 | 처음 알림을 저장할 때만 물음. 거부 시 "설정에서 알림 켜기" 안내, 시각은 저장됨 |
| 예약 업무 | 미래 날짜 업무에 알림을 걸면 그 시각에 울림. 완료·삭제하면 자동 취소 |
| 미루기 | 업무를 미루면 알림도 같은 간격으로 따라감(오늘 15시 → 미룬 날 15시). 다른 기기에서 이미 옮긴 값은 두 번 안 옮김 |
| 알림 버튼 | '완료', '10분 뒤 다시' |
| iOS 제한 | 앱당 예약 알림 64개 → 가까운 순 60개만 예약, 나머지는 앞의 것이 지나면 순서대로 예약 |
| 위젯 | 홈(소·중·대) + 잠금화면(사각·원형·한 줄). 오늘까지의 미완료(밀린 것 빨간 원) 표시. 자정에 스스로 다시 거름 |
| 위젯 탭 | 위젯 전체 → `worklog://today`, 중·대형 항목 → `worklog://day/<날짜>?task=<id>` |

## 4. 빌드 (개발 빌드 필요 — Expo Go 에서는 위젯이 안 됨)

- `npx expo prebuild --clean` 후 `npx expo run:ios` 또는 EAS 개발 빌드.
- **app.json 에 `ios.appleTeamId` 를 넣어야** 위젯 타깃 서명이 됩니다. [확인 필요: 팀 ID]
- App Group `group.com.webyigit.worklog` 은 Apple Developer 에서 앱·위젯 둘 다에 켜져 있어야 합니다(EAS 는 자동 등록).
- expo-notifications 가 `aps-environment`(푸시 권한)을 넣습니다. 무료 개인 개발자 계정은 이 권한이 안 되므로 유료 계정이 필요할 수 있습니다. [확인 필요: 계정 종류]
- 위젯은 iOS 17 이상에서 보입니다.
- 스토어/TestFlight 배포는 하지 않았습니다(사전 승인 필요).

## 5. Android (나중)

`src/widget/storage.android.ts` 주석 참고. Expo 로컬 모듈(SharedPreferences 저장 + AppWidgetManager 갱신) + Jetpack Glance 위젯이 같은 JSON(`snapshot.ts`)을 읽으면 됩니다. 알림은 이미 안드로이드 채널(`task-reminders`)까지 들어가 있어 그대로 동작합니다.
