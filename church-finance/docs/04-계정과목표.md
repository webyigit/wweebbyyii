# 04. 계정과목표 (초안)

작성: 2026-09-28 · 근거: 주간 파일 `총`·`MM-DD`·부서 시트, 상반기 지출 상세, 주일헌금현황. 금액(예산)은 여기에 적지 않고 DB 에만 넣습니다.

프로그램의 모든 숫자는 이 표의 **코드**에 매달립니다. 엑셀처럼 이름 글자로 찾지 않으므로 이름을 바꿔도 집계가 깨지지 않습니다.

## 1. 회계 (3종)

| 코드 | 회계 | 예산 | 비고 |
|---|---|---|---|
| G | 일반회계 | 있음 (항목별) | 헌금 수입 → 부서별 지출 |
| S | 특별회계 | 없음 | 헌금 종류별로 잔액을 따로 관리 (받은 만큼만 씀) |
| M | 해외선교 | 없음 | 매주 받고 월말에 송금. 네팔 구호 같은 한시 헌금도 여기 |

- 기부금영수증 대상: 이름이 기록되는 과목 전부 (무명 제외).

## 3. 지출 과목 (부서 → 항목)

일반회계 지출은 **부서 13개 → 항목** 2단계. 항목마다 연 예산이 붙습니다.

|---|---|
| 예배부 | 부활절행사, 어린이주일행사, 어버이주일행사, 추수감사절행사, 성탄절행사, 임직및은퇴식행사, 오후예배행사 |
| 봉사부 | 일반접대, 주일식사, 교회김장 |
| 장년교육부 | 교역자훈련비, 제직회수련회, 항존직수련회, 평신도훈련비, 구역장·권찰수련회, 남선교회연합회 체육대회 |
| 교회학교부 | 유치부전도사 사례비, 아동부전도사 사례비, 중고등부전도사 사례비, 교사대학, 유치부교육비, 아동부교육비, 중고등부교육비, 다드림청년공동체 교육비, 각부 공과금, 교회학교운영 |

| 관리부 | 주보발행비, 인쇄비, 광고비, 사무용품비, 소모품비, 비품수리비, 교회당유지비, 공공요금 |
| 차량관리부 | 차량보험료, 차량정비·검사료, 자동차세등, 유류비 |

| 재정부 | 원로목사사례비, 담임목사사례비, 목양비, 총회연금지원금, 노회상회비, 대출이자, 예비비 |

(시트마다 부서 이름이 조금씩 다름: `봉사`/`봉사부`, `선교부`/`이웃사랑`/`이웃사랑선교부`, `특별사역`/`특별사역팀` → 프로그램에서는 코드 하나로 통일하고 화면 이름은 담당자가 정함.
엑셀 `총` 시트 기준으로 12개 부서가 예산을 가지며, 13번째는 부서장 표에만 있는 구분이라 첫 이관 때 확인.)

특별회계·해외선교 지출은 **어느 헌금에서 나갔는지**(S-NEIGHBOR, S-FLOWER, S-BUILD, M-…)만 고르면 됩니다.

| NH-LOAN | 농협 대출 | |

| WR-FX | 우리 외화 | |

## 6. 이관할 때 이름 맞추기

엑셀에는 같은 과목이 표기만 다르게 적힌 경우가 있습니다 (`꽃꽂이`/`꽃꽃이`, `총회연금지원`/`총회연금지원금`, `담임목사례비`/`담임목사사례비` 등).
이관 스크립트에 **별칭표**를 두어 모두 같은 코드로 모읍니다. 별칭표는 실데이터가 아니므로 저장소에 둡니다.
